# 版本变更记录规范

## 文件命名

`releases/vX.Y.Z.md`，与 `package.json` 中的 `version` 字段一致。

## 格式模板

```markdown
【vX.Y.Z】 YYYY-MM-DD

一句话概述本次发布的主题

【新增】

【改进】

【修复】

【测试】
```

## 章节说明

| 章节 | 用途 | 何时出现 |
|------|------|---------|
| 标题行 | 版本号 + 发布日期 | 必填 |
| 概述行 | 一句概括本次发布的核心变更 | 必填 |
| 【新增】 | 全新功能或模块 | 有新功能时 |
| 【改进】 | 既有功能的体验/UI/性能优化 | 有优化时 |
| 【修复】 | Bug 修复 | 有修复时 |
| 【测试】 | 测试覆盖变化说明 | 测试数有变化时 |
| 【架构优化】 | 重构、代码质量改进（不影响功能） | 有重构时 |

## 条目格式

每条由**两行**组成：

```
emoji 标题（简短描述）
正文（必要的补充说明，一句话即可）
```

- emoji + 标题之间无空格
- 标题不换行，全文在同一行
- 正文另起一行，可选

## 常用 emoji

| 章节 | emoji | 含义 |
|------|-------|------|
| 新增 | 📝 | 新功能 |
| 新增 | 📋 | 新页面/新入口 |
| 新增 | ⚙️ | 新配置/新设置 |
| 改进 | 🎨 | UI/样式改进 |
| 改进 | 🗑️ | 交互优化 |
| 改进 | 📁 | 资源/文件整理 |
| 修复 | 🐞 | Bug 修复 |
| 测试 | 🧪 | 测试相关 |
| 架构 | 🔧 | 重构/工具 |
| 架构 | 🎯 | 代码质量/去重 |
| 架构 | 🔬 | 配置/规范化 |
