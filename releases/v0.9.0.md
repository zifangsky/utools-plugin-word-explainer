📝 新增 flomo 同步功能
查词结果右侧增加 flomo 图标按钮，点击后将 AI 解释原文一键同步到 flomo。支持自定义 API 端点、笔记标签（默认 #English/vocabulary），使用 Node.js https 模块发送请求

📋 新增查词历史详情页同步
在查词历史界面选中记录后，右侧详情区同样显示 flomo 同步按钮，支持将历史记录中的单词解释同步到 flomo

⚙️ 新增双卡片设置布局
设置页重组为"基本设置"和"同步到其他笔记应用"两个卡片，flomo 端点和标签在同步卡片中配置
