【v1.0.0】 2026-09-27

新增「匹配指令」与单词朗读，输入校验放宽并优化启动性能

【新增】
📝 新增「匹配指令」——主输入框输入英文单词即可直接查询
复制英文单词后呼出 uTools（Alt+Space），候选中直接出现「单词详解」，选中即自动预填并生成详解，无需键入指令名。

📝 新增首页结果区朗读按钮
结果区单词音标旁新增朗读按钮，点击即朗读当前查词；与查词历史界面的朗读能力统一由 `useWordAudio` hook 提供

【改进】
🎨 查词输入归一化
自动去除首尾空格并转为小写，`Hello`、`  Hello  ` 这类大小写与空格误输均可正常查询；AI 提示词、查词历史记录与 flomo 笔记标题三处保持一致

🗑️ 输入校验放宽至字母 / 连字符 / 撇号
首页手输支持 `well-known`、`don't`、`state-of-the-art` 等词形；仍要求至少含一个字母，故 `-`、`--` 等纯符号输入会被拒绝并提示（匹配指令侧保持纯字母口径不变）

⚡ 启动路径性能优化
移除挂载期的模型列表远程请求与 flomo 标签同步 IPC 读取，改由设置页按需加载，消除首屏阻塞

【架构优化】
🔧 新增 `src/word-audio/` 模块统一朗读能力
消除 main-page 与 history-view 对 SpeechSynthesis 的重复实现
