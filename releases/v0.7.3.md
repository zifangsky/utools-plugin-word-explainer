# v0.7.3 — 首个公开发布版本

> 发布日期：2026-05-04

## 新增功能

### 单词查询主界面
- 输入英文单词后流式返回 AI 生成的 7 板块结构化详解
- 自定义 Markdown 渲染器：段落/分割线/嵌套列表（3 层）/加粗标题
- 设置页面：AI 模型选择下拉框，偏好自动持久化
- 暗色模式自适应（`prefers-color-scheme: dark`）

### MCP 工具
- 注册 `explain_word` 工具，将查词能力暴露给外部 AI Agent
- 流式调用 + 每 2s 进度上报（线性估算，15s 上限）
- Preload 链式加载体系：`services.js` → `tools.js` → `prompt.js`

### 工程化
- React 19 + Vite 6 开发环境
- Vitest 4 + Testing Library 测试框架
- 58 个测试用例覆盖 7 个模块
- 工厂函数 + 依赖注入模式，模块高内聚可独立测试

## 修复的问题

- 设置页面标题与内容未对齐
- 搜索栏和设置面板未居中
- plugin.json `tools` 字段格式错误（数组→对象）
- 部分 AI 模型偶发性在正文前输出思考/推理过程

## 已知限制

- 不支持短语、句子或中文输入，仅单个英文单词
- 所有内容由 AI 生成，不接入外部词典 API
- 不持久化查询历史记录
