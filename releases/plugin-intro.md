# 英语单词详解 — 插件应用介绍

## 简介

输入任意英文单词，AI 自动生成涵盖 **7 大板块** 的结构化详解，让背单词不止于记释义。同时将查词能力以 MCP 工具形式暴露，供 Claude Code 等 AI Agent 在对话中自主调用。

## 核心功能

### 单词查询
在 uTools 搜索框输入触发词进入插件，键入英文单词后回车，流式返回以下内容：

1. **词义解析** — 2~4 个核心义项，含范围标注、英文例句和中文翻译
2. **词性用法** — 主要词性、比较级/最高级、派生词及例句
3. **语境应用** — 物理/抽象/数据等语境分类，配场景化例句
4. **常见搭配** — 修饰具体名词、抽象名词、副词搭配三类
5. **词源故事** — 拉丁/希腊/古英语词源追溯，词根词缀拆解
6. **记忆技巧** — 词根拆解法 + 形象联想法
7. **同义词辨析** — 3~5 个近义词语感对比，各配例句

### 模型选择
设置页面支持从 uTools 可用模型列表中选择偏好的 AI 模型，偏好自动持久化保存。

### MCP 工具
插件安装后自动向 AI Agent 暴露 `explain_word` 工具，支持流式调用和进度上报，无需任何额外配置。

## 触发方式

在 uTools 搜索框输入以下任意关键词进入插件：

- `explain`
- `查词`
- `word`
- `vocabulary`

## 运行要求

- uTools 6.0+
- 插件需调用 uTools AI API 生成解释，请确保 uTools 已配置可用的 AI 模型
