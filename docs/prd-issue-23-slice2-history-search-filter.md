## 1. 概述

在 Slice 1 的历史视图基础上，增强左栏的搜索和筛选能力，使用户能够快速定位历史记录中的特定单词。

---

## 2. 功能需求

### 2.1 搜索与筛选 UI

- **文件**: `src/history-view/index.jsx` + `index.css`（修改）
- **新增控件**（位于左栏顶部）:
  1. **单词搜索输入框** — 输入关键词
  2. **搜索按钮** — 触发搜索（回车或点击）
  3. **时间下拉筛选框** — 选择时间范围

### 2.2 时间筛选

| 选项值 | 显示标签 | 含义 |
|--------|---------|------|
| `1d` | 1天 | 最近 1 天 |
| `3d` | 3天 | 最近 3 天 |
| `7d` | 7天（默认） | 最近 7 天 |
| `15d` | 15天 | 最近 15 天 |
| `30d` | 30天 | 最近 30 天 |
| `all` | 全部 | 不限时间 |

- **默认值**: `7d`（初始化时加载最近 7 天的记录）
- **切换行为**: 重新调用 `getHistoryRecords(db, timeFilter)` 加载数据，清空当前选中状态

### 2.3 搜索逻辑

- **类型**: 前端过滤
- **匹配字段**: `word`（大小写不敏感）
- **触发方式**: 回车键或点击搜索按钮
- **空查询**: 显示全部已加载记录
- **与筛选组合**: 先按时间筛选加载数据，再在前端按关键词过滤

### 2.4 样式要求

- 搜索框、筛选框、搜索按钮样式与现有界面风格统一
- 暗色模式适配（`@media (prefers-color-scheme: dark)`）
